Transfer-Encoding Chunked

¿Qué es Chunked Encoding?

Es enviar datos en PEDAZOS (chunks) cuando NO sabes el tamaño total de antemano.

  • POST Normal: "Te envío EXACTAMENTE 100 bytes"
  • POST Chunked: "Te envío pedazos, te aviso cuando termine"
POST Normal
POST /upload HTTP/1.1 Content-Length: 13 Hola, mundo!

✓ Dice EXACTAMENTE cuántos bytes va a enviar
✓ Envía todo de una vez

POST Chunked
POST /upload HTTP/1.1

✓ NO dice el tamaño total
✓ Envía en pedazos
✓ El último chunk es "0" (fin)

Nota Importante sobre Chunked en Navegadores

Los navegadores NO permiten forzar Transfer-Encoding: chunked desde JavaScript.

El navegador decide automáticamente cuándo usar chunked encoding. Esta demo muestra:

  • Cómo tu servidor recibe y decodifica peticiones chunked
  • La diferencia entre Content-Length y Transfer-Encoding
  • Que tu implementación funciona correctamente

Para probar chunked REAL: Usa curl o ./test_chunked.sh desde la terminal

¿Cómo verificar que funciona?
  1. Haz click en cualquier botón de arriba
  2. Abre las DevTools (F12) → pestaña Network
  3. Busca la petición a /autoindex
  4. En Headers, busca:
    • Request Headers: Transfer-Encoding
    • Content-Type
  5. Si ves "Transfer-Encoding: chunked" → ¡Funciona!
