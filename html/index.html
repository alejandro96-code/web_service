Web Service

¿Qué es un Web Service?

Un servidor web es un software que procesa solicitudes HTTP del cliente (navegador) y responde con recursos como páginas HTML, imágenes, archivos, etc. Este proyecto implementa un servidor HTTP/1.1 compatible con las especificaciones estándar, capaz de servir contenido estático, manejar CGI, realizar operaciones CRUD y gestionar múltiples conexiones simultáneas.

Cómo Funciona el Proyecto

🔧 Arquitectura
  • Servidor HTTP/1.1 escrito en C++
  • Multiplexación I/O con select()
  • Gestión de múltiples servidores virtuales
  • Sistema de configuración tipo NGINX
⚙️ Características
  • Métodos HTTP: GET, POST, DELETE
  • Soporte para CGI (Python, PHP)
  • Transferencia chunked encoding
  • Páginas de error personalizadas
  • Autoindex de directorios
  • Redirecciones HTTP

El servidor procesa cada petición parseando la solicitud HTTP, buscando la ubicación (location) correspondiente en la configuración, validando permisos de métodos permitidos, y finalmente ejecutando la lógica apropiada (servir archivo estático, ejecutar CGI, o realizar operación de archivo).

Códigos de Estado HTTP

Los códigos de estado HTTP indican el resultado de una solicitud. Se dividen en varias categorías: 2xx (Éxito), 3xx (Redirección), 4xx (Errores del cliente) y 5xx (Errores del servidor).

Códigos de Éxito (2xx)
  • 200 OK - La solicitud se procesó correctamente y se devuelve el contenido
  • 201 Created - El recurso se creó exitosamente (POST)
  • 204 No Content - La solicitud se procesó correctamente pero no hay contenido que devolver (DELETE)
Códigos de Redirección (3xx)
  • 301 Moved Permanently - El recurso se ha movido permanentemente a otra URL
  • 302 Found - Redirección temporal a otra URL
Errores del Cliente (4xx)
  • 400 Bad Request - La sintaxis de la solicitud es incorrecta o malformada
  • 403 Forbidden - El servidor entiende la petición pero se niega a autorizarla
  • 404 Not Found - El recurso solicitado no existe en el servidor
  • 405 Method Not Allowed - El método HTTP no está permitido para este recurso
  • 413 Payload Too Large - El cuerpo de la solicitud supera el tamaño máximo permitido
  • 418 I'm a teapot - Código de broma del protocolo HTCPCP (RFC 2324)
Errores del Servidor (5xx)
  • 500 Internal Server Error - Error genérico del servidor al procesar la solicitud
  • 501 Not Implemented - El servidor no soporta la funcionalidad requerida
