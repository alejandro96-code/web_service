🚀 Prueba de CGI (Common Gateway Interface)

💡 ¿Qué es CGI?

CGI permite ejecutar scripts externos (Python, PHP, etc.) en el servidor y devolver su salida como respuesta HTTP.

Proceso:
  1. El servidor detecta archivos .py o .php
  2. Usa fork() para crear un proceso hijo
  3. Usa pipe() para comunicación stdin/stdout
  4. Usa execve() para ejecutar el intérprete
  5. Captura la salida y la devuelve como respuesta

⚠️ Requisitos del Sistema
  • Python 3: which python3 debe mostrar /usr/bin/python3
  • PHP-CGI (opcional): which php-cgi o instalar: sudo apt install php-cgi
  • Permisos: Los scripts deben ser legibles por el servidor

🔍 Verificar Instalación

Ejecuta estos comandos en la terminal:

# Verificar Python
which python3
python3 --version

# Verificar PHP (opcional)
which php-cgi
php-cgi --version

# Dar permisos a los scripts
chmod +x html/*.py
chmod +x html/*.php

✅ ¿Cómo saber si funciona?

  • Haz click en uno de los botones de arriba
  • Si ves contenido HTML generado dinámicamente → ✅ Funciona
  • Si ves un error 500 → El intérprete no está instalado o no tiene permisos
  • Si ves un error 404 → El archivo no existe
  • Si ves código fuente → CGI no está ejecutándose (problema en el servidor)
📝 Crear tu Propio Script CGI
Ejemplo Python:
#!/usr/bin/env python3
print("Content-Type: text/html")
print()
print("<html><body>")
print("<h1>Hola desde Python CGI!</h1>")
print("</body></html>")

Guarda como: html/mi_script.py

Accede en: http://localhost:8080/mi_script.py
