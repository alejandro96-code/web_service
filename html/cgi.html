CGI (Common Gateway Interface)

¿Qué es CGI?

CGI permite ejecutar scripts externos (Python, PHP, etc.) en el servidor y devolver su salida como respuesta HTTP.

Proceso:
  1. El servidor detecta archivos .py o .php
  2. Usa fork() para crear un proceso hijo
  3. Usa pipe() para comunicación stdin/stdout
  4. Usa execve() para ejecutar el intérprete
  5. Captura la salida y la devuelve como respuesta

¿Cómo saber si funciona?

  • Haz click en uno de los botones de arriba
  • Si ves contenido HTML generado dinámicamente → ✅ Funciona
  • Si ves un error 500 → El intérprete no está instalado o no tiene permisos
  • Si ves un error 404 → El archivo no existe
  • Si ves código fuente → CGI no está ejecutándose (problema en el servidor)
