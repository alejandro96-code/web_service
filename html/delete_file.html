Eliminar Archivos

Método DELETE

Este formulario utiliza el método HTTP DELETE para eliminar archivos del servidor.

  • Los archivos se eliminan del directorio /autoindex
  • Devuelve código 204 No Content si tiene éxito
  • Devuelve código 404 Not Found si el archivo no existe
Formulario de Eliminación
Escribe el nombre del archivo (ej: file.txt)
